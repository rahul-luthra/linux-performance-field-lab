Interpretation guardrails
Load average includes runnable work and uninterruptible waits. It is not CPU utilization.
Filesystem cache is useful. Check available memory and memory pressure before treating low free memory as a fault.
Iowait is a clue with accounting limitations. Device busy time is not a universal capacity ceiling, especially for parallel storage.
Host-wide signals can hide a constrained container, a single busy core, or an application lock.


Coverage & missing evidence
Not collected: application latency/errors, process attribution, per-core utilization, cgroup limits/throttling, TCP retransmissions, hardware errors, filesystem capacity/inodes, or disk error logs. A quiet report does not certify a healthy service.
