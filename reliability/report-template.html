The service is running. Can users get a quote?

A frontend on one Linux VM calls a price service on a second VM. Six measured phases show the difference between a process answering a health probe and a user getting a correct response on time.

Incident timeline

Each phase sends 24 quote requests at four per second and six liveness probes. The lab target is a correct HTTP 200 within 250 ms. The p95 includes errors as well as successful responses.

What restored the service


Starting the dependency again restored successful quotes after the outage. When the dependency was slow, a 200 ms timeout returned a 504 sooner. Those requests still missed the lab target. Removing the injected delay restored correct quotes within the target.


The frontend process stayed active throughout, and the liveness endpoint answered every probe. The quote route exercised the remote dependency and showed the errors that a liveness probe would miss.
